# 宠物趣味表情包 Skill

把宠物照片变成可爱、有趣、色彩丰富的聊天表情包。支持先做合集预览、再逐张精修，也可协助整理社交平台教程。

## 使用前

你需要一个支持读取 Agent Skills 的客户端，以及可用的图片生成工具。Skill 是创作流程说明，不自带图片模型或免费额度。实际图像质量、费用和可用功能由所选服务决定。

## 安装与使用

在支持 Skills 的客户端中，可请助手从本仓库的 `skills/pet-sticker-playbook` 安装技能；具体安装方式以客户端为准。重新加载技能后，上传一张宠物照片并输入：

> 使用 pet-sticker-playbook，把我的宠物做成 12 张可爱有趣的聊天表情包。先做 3×4 预览，再精修喜欢的单张。保留它的毛色、花纹和脸型。

不支持安装 Skills 的图片工具，也可阅读 [SKILL.md](skills/pet-sticker-playbook/SKILL.md)，按其中的设计要求编写提示词，再上传照片作为参考。豆包各版本对 Skills 的导入支持尚未验证。

## 输出与检查

- 合集是风格预览；用于聊天的独立图片需要单独生成或裁切。
- 检查宠物身份、中文文字、边距和动作。AI 生成结果可能需要修正。
- 动图需另有可用的动画工具；逐帧或补帧效果不能保证连续流畅。
- 使用有权使用的宠物照片和素材，生成作品前请查看所用服务的费用与条款。
